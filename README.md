# queue_talon_bot

Telegram-бот для выдачи талонов в очереди для студенческой группы. Студенты сами занимают номер в очереди (например, на сдачу лабораторных), а администраторы управляют очередью через отдельное меню.

## Возможности

**Для всех пользователей**
- 🎟 **Взять талон** — выбрать желаемый номер или ввести `0`, чтобы занять ближайшее свободное место.
- ❌ **Освободить место** — выйти из очереди (с подтверждением). Остальные номера пересчитываются без пропусков.
- 📋 **Показать очередь** — список участников, отсортированный по номерам.

**Для администраторов** (кнопка «🛠 Редактор очереди»)
- 🟢 / 🔴 Открыть и закрыть очередь для новых участников (администраторы могут занимать места и при закрытой очереди).
- ✏️ Изменить номер талона.
- 🔁 Поменять двух участников местами.
- 🗑 Удалить участника из очереди.
- 🧹 Очистить очередь целиком.
- 🔄 Обновить отображение очереди.

## Команды

| Команда | Доступ | Описание |
|---|---|---|
| `/start` | все | Показать главное меню |
| `/take_talon [номер]` | все | Взять талон. Без аргумента или с `0` выдаётся первый свободный номер |
| `/dismiss_talon` | все | Выйти из очереди (с подтверждением) |
| `/queue` | все | Показать текущую очередь |
| `/open_queue` | админы | Открыть очередь для новых участников |
| `/close_queue` | админы | Закрыть очередь для новых участников |
| `/clear_queue` | админы | Очистить очередь |

## Стек

- Python 3
- [aiogram](https://docs.aiogram.dev/) 3.x (FSM, `MemoryStorage`, long polling)
- python-dotenv
- Docker / Docker Compose

## Быстрый старт

### 1. Получите токен

Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.

### 2. Клонируйте репозиторий

```bash
git clone https://github.com/hekemi/queue_talon_bot.git
cd queue_talon_bot
```

### 3. Создайте файл `.env`

```env
BOT_TOKEN=123456:ABC-your-token
ADMIN_USERNAMES=username1,username2
```

- `BOT_TOKEN` — токен бота от BotFather (обязателен).
- `ADMIN_USERNAMES` — Telegram-username администраторов через запятую, без `@` (регистр не важен). Если не задать, админов не будет.

### 4a. Запуск через Docker (рекомендуется)

```bash
docker compose up -d --build
docker compose logs -f
```

Контейнер называется `queue-talon-bot` и перезапускается автоматически (`restart: unless-stopped`).

### 4b. Запуск локально

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

При старте бот проверяет токен через `get_me()`, удаляет вебхук и пропускает накопившиеся сообщения (`drop_pending_updates=True`).

## Ограничения

- Очередь, номера и состояния FSM хранятся **в памяти**: после перезапуска бота очередь сбрасывается.
- Одна общая очередь: отдельных групп или предметов нет.
- Для администраторов у аккаунта должен быть установлен Telegram-username.
